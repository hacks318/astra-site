DÚVIDAS FREQUENTES

Antes de instalar.

Em quais computadores Astra funciona?

Esta versão é um aplicativo para Windows 10 ou 11 de 64 bits. macOS e Linux não são suportados por este instalador.

Preciso instalar Node.js?

Não. O instalador já contém o aplicativo. Node.js só é necessário para quem desenvolve ou gera o instalador a partir do código.

A IA local vem instalada?

Não. Para usar IA local, instale o Ollama e baixe um modelo separadamente. Astra também pode se conectar a uma API compatível configurada por você.

A Astra se conecta a qualquer TV?

O controle disponível é para TVs LG webOS compatíveis na mesma rede local. O pareamento precisa ser aprovado na tela da TV.
